What it does

启动、切换、收藏、记录，一块玻璃管到底。

它不替你隐藏复杂度，而是把每个渠道当前的状态、可执行的动作和不可用的原因，一条条讲清楚。

01 / CHANNELS

三份渠道档案

国服官方、哔哩哔哩、Steam 国际服各留一份档案：安装位置、组件状态、能不能启动，分开呈现。切换档案不会把「共用内容」误报成「共用登录」。

02 / PREFLIGHT

启动前，先预检

路径在不在、组件齐不齐、进程有没有在跑。能启动就启动，不能启动，告诉你为什么。

03 / GALLERY

相册与收藏

游戏截图按日期浏览，收藏可加保护；原生页面保持只读，原图一个字节都不动。

04 / JOURNAL

奇想手账

登录天数、游戏时长、衣橱摘要，保存成本地快照，想翻的时候都在。

05 / WISHES

心愿共鸣记录

导入后增量合并，重复同步不会覆盖已有历史。

06 / SNAPSHOT

一键游戏截图

全局快捷键截图，PNG、AVIF、JPEG XL 随你选；HDR 画面自动另存一份 SDR，色彩管理和自动复制也在设置里说明白。

Get started

三步，把 Nikkiward 带回家。

  1. 下载

    从 GitHub Releases 获取 Windows x64 安装包或便携 ZIP，附 SHA-256 校验文件。

  2. 确认档案

    首次启动后，在档案页确认各渠道的安装路径。

  3. 预检并启动

    回到启动页，跑一遍预检，然后进游戏。
